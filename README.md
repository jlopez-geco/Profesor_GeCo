# Profesor GeCo

Web app de autoaprendizaje con tarjetas y repetición espaciada (FSRS), para interiorizar conceptos técnicos (Supabase, AWS, backend, etc.) e idiomas con ejercicios estilo Duolingo.

Este README se irá completando a lo largo de los hitos del proyecto (ver `legacy/` y `ui-v0/` para el material de referencia histórico).
